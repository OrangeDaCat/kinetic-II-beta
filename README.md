# KINETIC-II — beta

A first-person speed / parkour game. You are a brain scan that escaped into **KINETIC-II**, a conveyor-enforcement
robot, and you have to run your way out of the facility it was built in.

This repository holds the **beta builds** (see *Releases*). Windows only for now.

## Play

1. Download `KINETIC-II-beta-v<version>.zip` from the latest release.
2. Unzip it and run `KINETIC-II-beta.exe` — nothing to install.
3. The green terminal is the main menu: **WAKE UNIT** starts, **SECTOR SELECT** picks a level.

## Controls

| | |
|---|---|
| Move / look | W A S D / mouse |
| Sprint | Shift |
| Jump | Space (tap = hop, hold = full jump) |
| Crouch / slide | Ctrl (slide: crouch while running fast) |
| Grab, kick, interact | E |
| Torch / throw | F / Q |
| Pause | Esc |

## Levels

- **Level One** — basic training: running, jumping, crouch, slide, mantle, the drop
- **Level Two** — the facility: belts, the clamp, booster, poles, gates, hammers, the magnet wall, the unlit sector
- **Parkour** — timed escape course
- **Playground**, **Sector 07** — test zones

## Settings

Pause → **SETTINGS**: graphics preset (it picks **LOW** on integrated graphics), window mode, V-sync, frame cap, field
of view, camera shake, audio volumes, mouse sensitivity, invert Y.

## Known

Beta — expect rough edges. Saves and settings live in `%APPDATA%\Godot\app_userdata\KINETIC-II\`.
